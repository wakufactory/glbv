# GLBV

three.jsをCDNから読み込む、静的なGLBファイルビューアーです。

クライアント用のHTML・CSS・JavaScriptとサンプルGLBは `html/` にまとめています。静的ホスティングではこのフォルダを公開してください。開発用サーバーも `html/` を配信します。`scripts/` は開発用サーバーとサンプル生成、`tests/` はテストです。

## 起動

```sh
npm start
```

[https://localhost:8443](https://localhost:8443) を開きます。Node.js 22以降とOpenSSL（証明書生成時）が必要です。npmを使わず `node scripts/serve.mjs` でも起動できます。ビルドやnpmパッケージのインストールは不要です。初回のthree.jsと圧縮デコーダーの取得にはインターネット接続が必要です。

初回起動時にサーバー用の自己署名証明書を `.certs/` に生成します。localhost・検出したLAN IP・ホスト名を証明書に含めます。端末からは起動時に表示される `https://<LAN IP>:8443` にアクセスしてください。**クライアント証明書は要求せず、端末への証明書インストールも行いません。** ブラウザーには自己署名証明書の警告が出ます。

```sh
# ポートや証明書に含めるLAN IPを指定
npm start -- --port 8443 --san 192.168.1.10
# 従来のHTTP起動
npm run start:http
```

サーバーはNode.js標準の `https`／`http` モジュールで実装しています。証明書は再利用し、有効期限が近い場合や対象IP・ホスト名が変わった場合に再生成します。秘密鍵は所有者のみ読み書き可能にし、HTTPSサーバーは `.certs/` などの隠しファイルとディレクトリー一覧を配信しません。

## PWA・オフライン利用

ブラウザーの「インストール」または「ホーム画面に追加」でPWAとして利用できます。Service Workerの利用には、ブラウザーが信頼するHTTPSまたはlocalhostが必要です。自己署名証明書の警告を通過しただけでは登録できない場合があります。

初回アクセス時に画面一式、サンプルGLB、three.js r187の本体・依存アドオン・Draco／Meshopt／KTX2デコーダーをキャッシュします。初回のキャッシュ完了後は、通常のブラウザー表示でもPWAでもオフラインで起動し、端末内の自己完結したGLBや同梱サンプルを表示できます。URLで指定した任意のGLBはキャッシュしないため、取得には接続が必要です。

アプリ更新時は `html/sw.js` のキャッシュバージョンを変更してください。新しいキャッシュの準備後、既存のビューアーをすべて閉じて開き直すと更新され、旧キャッシュを削除します。

開発時は `http://localhost:8080/?nocache=1` のように `nocache=1` を付けると、このビューアーのService Worker登録とPWAキャッシュを削除して通常のネットワーク読み込みに切り替えます。既存のService Workerがページを制御している場合は自動で一度再読み込みします。`nocache=1` を外して開くとPWAキャッシュが再び有効になります。ほかのパラメータと併用する場合は `?url=./sample.glb&nocache=1` のように指定してください。

## 操作

- 「開く」またはドラッグ＆ドロップで `.glb` を読み込みます。ファイルは端末内で処理し、アップロードしません。
- ドラッグで回転、ホイール／ピンチでズーム、右ドラッグ／2本指ドラッグで平行移動。
- `F` または ⛶ でモデル全体を表示。
- 右上のバーの「オブジェクト」をクリックするとGLBのシーン／ノード階層を開閉できます。初期状態は閉じています。「照明」とは同時に開きません。矢印で枝を開閉し、チェックボックスで各ノードの表示を切り替えます。親を非表示にすると子も隠れますが、子の個別設定は保持されます。表示設定はAR／VRにも反映され、GLBを開き直すとリセットされます。
- 背景は黒（初期値）、中間グレー、白系から選択。
- カメラモードは「通常」（初期値）、「立体視（平行法）」、「立体視（交差法）」から選択。立体視ではカメラを左右にずらし、両眼視差のある画像を横に2枚描画します。平行法は左目用／右目用、交差法は右目用／左目用の順です。注視点を視差ゼロの基準にし、視点間隔は注視点までの距離の1/30に自動調整します。通常／立体視の切り替え時はモデル全体を表示し直します。回転・ズーム・アニメーション・描画設定は左右に共通で反映されます。AR／VRでは端末のXRカメラを使用し、終了後に選択したモードへ戻ります。
- レンダリング方法を「シェーディング」（初期値）、「ワイヤフレーム」、「面法線RGB」から切り替えられます。面法線RGBはGLB全体のルート座標における三角形の法線をRGBに対応させます。GLB内のノード変換・アニメーションを反映し、視点移動やビューアー側でのモデル回転では色は変わりません。ワイヤフレームは背景に合わせた明暗の線で表示します。描画モードはAR／VRにも反映されます。
- 照明はシェーディングのみに適用されます。他のモードでは照明操作を非表示にし、シェーディングに戻すと直前の照明設定を使用します。
- 「照明」を開くと環境マップ（0〜3）、半球ライト（0〜3）、平行光（0〜10）の強度を個別に調整できます。初期値は0.35／0.50／2.50で、変更は即時反映されます。再読み込みすると初期値に戻ります。
- アニメーションがあれば最初のクリップをループ再生。クリップ選択、一時停止、シーク、0.5／1／2倍速に対応。`Space` で再生／一時停止。
- 「アニメーションのサンプルを見る」で同梱のGLBを表示。`python3 scripts/make-sample.py` で再生成できます。

## URLから自動読み込み

ページの `url` クエリパラメータにGLBの相対パスまたはHTTP(S) URLを指定すると、起動時に自動で読み込みます。アニメーションも通常どおり自動再生します。

```text
https://localhost:8443/?url=./sample.glb
https://localhost:8443/?url=./models/model.glb
https://localhost:8443/?url=https://example.com/models/model.glb
```

相対パスはビューアーのページURLを基準に解決します。URLに `&`、`#`、`+` などが含まれる場合は、`encodeURIComponent` または `URLSearchParams` でパラメータの値をエンコードしてください。

```js
const viewer = new URL('https://viewer.example.com/');
viewer.searchParams.set('url', 'https://example.com/model.glb?version=2&token=abc');
console.log(viewer.href);
```

別ドメインのGLBは配信元のCORS許可が必要です。HTTPSのビューアーからはHTTPSのGLBを指定してください。取得・解析エラーは画面上に表示します。URLで指定する場合もGLB内のテクスチャやバッファは埋め込みが必要です。

## WebXR

対応端末・ブラウザーではGLBを読み込むとAR／VRボタンが有効になります。HTTPSまたはlocalhostが必要です。スマートフォンやヘッドセットからLANのHTTPアドレスを開くと通常WebXRは利用できません。標準の `npm start` はLANから使える自己署名HTTPSで配信します。

自己署名証明書をブラウザーで許可した後のWebXR利用可否は、端末・ブラウザーの実装に依存します。HTTPS配信だけでWebXRの利用を保証するものではありません。WebXRにはセキュアコンテキストが必要です。証明書のインストールなしでアクセスしてもブラウザーが安全な接続として扱わない場合は、端末で信頼済みの公開CA証明書を使った配信、または開発用のlocalhostポート転送が必要です。サーバーからブラウザーの証明書検証を無効にはできません。

参考：[WebXRの要件（Google）](https://developers.google.com/ar/develop/webxr/requirements)、[自己署名証明書での開発（Immersive Web SDK）](https://iwsdk.dev/guides/02-testing-experience.html)。

XRではモデルの初期姿勢の最大辺を約1mに揃えて前方に表示します。ARのヒットテストが利用できる場合は緑色のリングが現れ、タップ／コントローラーの選択でモデルを配置・再配置できます。終了はブラウザー／ヘッドセットのシステムUIから行います。ARでは実空間を表示するため背景色は透明になります。XR終了後は通常のカメラと背景に戻ります。

WebXR非対応の環境（Safariなどを含む）ではAR／VRボタンを無効表示します。USDZ Quick Lookへの変換・フォールバックは含みません。

### VRのハンドジェスチャー

ハンドトラッキング対応端末では、VRに入る際に手の追跡を任意機能として要求します。ビューアーは手のモデルを描画しません。端末側のハンドトラッキングを有効にし、コントローラーを置いて操作してください。

- **片手のピンチ**：親指と人差し指をつまんだまま手を上下左右に動かすと、モデルの中心を軸に回転します。左右どちらの手でも操作できます。
- **両手のピンチ**：両手でつまみ、手の間隔を広げると拡大、狭めると縮小します。倍率は初期サイズの0.1〜5倍です。
- 指を離すと即停止し、慣性はありません。片手／両手の切り替えや追跡再開時は、その時点の手の位置から操作を再開します。
- XRカメラは頭の動きに従い、ジェスチャーはモデルの回転・拡縮に適用します。VR終了時にモデルの回転と倍率を初期状態へ戻します。ARでは従来の面配置を使用します。

ハンドトラッキング非対応の端末・ブラウザーでもVR表示は利用できますが、これらのジェスチャー操作はできません。

## 環境マップのカスタマイズ

環境マップは、three.js r187から取り込んだ `html/room-environment.js` の `RoomEnvironment` で生成します。このファイルを編集すると、部屋の材質・箱の配置・主照明の色や強度・光る面の位置や寸法を変更できます。初期設定は公式r187と同じです。

`mainLight` は主照明、`roomMaterial`／`boxMaterial` は壁と箱の材質、`light1`〜`light6` は映り込みを作る光る面です。光る面の明るさは `createAreaLightMaterial()` の引数、色は同関数の `emissive`、位置と大きさは各面の `position`／`scale` で指定します。変更後に再読み込みすると環境マップを再生成します。開発時は `?nocache=1` を使用してください。PWAへ配信する際は `html/sw.js` のキャッシュバージョンも更新してください。

取り込んだコードのMITライセンスは `html/licenses/three-LICENSE.txt` にあります。

## 対応範囲

three.js **0.187.0（r187）** に固定し、本体・アドオン・Draco／KTX2デコーダーをjsDelivrから取得します。GLTFLoader、OrbitControls、AnimationMixer、WebXRManagerを使用しています。

自己完結したGLBを対象とし、GLBに記載された外部テクスチャ／バッファのURLは取得しません。Draco、Meshopt、KTX2圧縮に対応。外部参照のあるモデルは、リソースをGLB内へ埋め込んでから開いてください。モデルのライトに加えてスタジオ環境光を使用します。
